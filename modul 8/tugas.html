TESTIMONI

Praktikum Desain Web sejauh ini terasa sangat seru dan membuka wawasan tentang alur kerja front-end masa kini. Hadirnya materi Bootstrap 5 benar-benar mempermudah kami dalam merancang tata letak web yang responsif berkat sistem grid 12 kolom dan komponen siap pakainya. Kami jadi tidak perlu repot lagi menulis ratusan baris CSS dari nol hanya untuk membuat tampilan web yang rapi, adaptif di layar ponsel maupun laptop, serta enak dipandang.

KRITIK

Di dalam modul praktikum, masih ada sedikit cuplikan kode dari Bootstrap versi 4, misalnya penggunaan atribut data-toggle. Hal ini sempat membuat tombol menu navigasi responsif tidak berfungsi ketika pertama kali dicoba, sehingga membutuhkan penyesuaian mandiri ke sintaks Bootstrap 5 (menggunakan data-bs-toggle) agar menunya bisa terbuka dengan normal.

SARAN

Ke depannya, panduan modul akan semakin relevan jika diperbarui secara berkala mengikuti dokumentasi Bootstrap versi stabil terkini agar tidak bingung saat mempraktikkannya. Selain itu, eksplorasi komponen interaktif modern seperti Modal, Offcanvas, atau Toast rasanya akan sangat menarik jika ditambahkan ke materi untuk variasi tugas praktikum.
